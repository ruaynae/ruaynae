# R21 · คลังเอกสาร (สัญญาจ้าง · แบบก่อสร้าง · BOQ · หนังสือรับรองผลงาน)

คำขอเจ้าของ 22 ต.ค. 2569: "อยากให้ระบบเก็บข้อมูล พวกสัญญาจ้าง แบบตามสัญญาจ้าง boq หนังสือรับรองผลงาน เพื่ออนาคตจะได้กลับมาค้นหาง่าย"

- ตาราง `project_files` (migration `20261023090000_project_files.sql`) · เจ้าของเท่านั้น · audit · guard ไฟล์ห้ามเปลี่ยน
- ไฟล์อยู่ R2 `files/<uuid>.<ext>` · อัปผ่าน presigned PUT (ไบต์ไม่ผ่าน Vercel) + `upload_intents` (thumb_key = object_key → sweep-orphans กวาดไฟล์ที่ไม่ได้บันทึก)
- ชนิดไฟล์ตัดสินจากนามสกุล เซิร์ฟเวอร์กำหนด content-type เอง · ไม่รับ html/svg/js
