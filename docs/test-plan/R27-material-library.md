# R27 · คลังวัสดุขออนุมัติ + เลือกเข้าหนังสือ + ตราประทับ (3 พ.ย. 2569)

คำขอเจ้าของ: "ผมอยากทำคล้าย ๆ เป็นคลังเก็บเอกสารประกอบการขออนุมัติวัสดุ อัปโหลดเอกสารวัสดุที่ใช้ประจำไปเก็บไว้ ตอนทำขออนุมัติวัสดุก็เลือกมาเลย
รายละเอียดมาอยู่ในหนังสือเลย ไม่ต้องไปนั่งหา นั่งเพิ่มทีละรายการ"

## คำตอบเจ้าของ

- ไฟล์แค็ตตาล็อก = **ทั้งรูปภาพและ PDF** (PDF แปลงเป็นรูปทีละหน้าในเบราว์เซอร์ ใช้ตัวแปลง `lib/pdf-pages.ts` เดิม)
- ตราประทับ = **ให้ระบบประทับให้ตอนแนบ** (เก็บรูปตราไว้ครั้งเดียว)
- เก็บไฟล์ที่ R2 เดิม · **หนังสืออ้างอิงไฟล์ในคลัง ไม่คัดลอก** (ประหยัดพื้นที่ · เจ้าของถามเรื่องพื้นที่ฟรีแล้วเห็นชอบ)

## การออกแบบ

- ตาราง `material_catalog` (ชื่อ · หมวด · รายละเอียดที่ขออนุมัติ · หมายเหตุ · `is_active`) + `material_catalog_pages` (หน้าแค็ตตาล็อก `catalog/<uuid>.<ext>` เรียงตาม `seq`)
  + `material_library_settings` (แถวเดียว · รูปตราประทับ) — เจ้าของเท่านั้น · migration `20261103090000_r27_material_library.sql`
- เมนู `/letters/library` (ปุ่ม "คลังวัสดุ" ในทะเบียนหนังสือ) · อัปโหลดผ่าน `POST /api/uploads/sign` (`purpose: 'catalog'`) → PUT ตรงเข้า R2 → `POST/PATCH /api/material-library`
- ในหนังสือ "ขออนุมัติใช้วัสดุ": ปุ่ม **เลือกจากคลังวัสดุ** → ติ๊กหลายรายการ → เติมแถวรายการ (ชื่อ + รายละเอียด + หมายเหตุ ; ช่องที่ขึ้นกับโครงการยังกรอกเอง) และต่อหน้าแค็ตตาล็อกท้ายหนังสือตามลำดับที่ติ๊ก
  · ใช้ได้ทั้งแบบแนบตาราง/ระบุในเนื้อหา (R26) · วัสดุ/หน้าที่มีอยู่แล้วไม่เติมซ้ำ
- `letter_photos.object_key` ชี้ `catalog/…` ได้: ถอด unique เดิม (คง unique เฉพาะ `letters/…`) · เพดาน 12 → **60 หน้า** · `stamped` ต่อหน้า · เลย์เอาต์ `p` = **1 รูปต่อ 1 หน้ากระดาษ**
- 🔴 ไฟล์ที่หลายแถวอ้างร่วมกัน ห้ามถูกลบตามแถวใดแถวหนึ่ง: ลบหนังสือ/เอารูปออกจากหนังสือ **ข้ามไฟล์ `catalog/`** · ลบหน้า/วัสดุที่หนังสือใช้อยู่ = trigger `guard_catalog_page_delete` → 409 `CATALOG_IN_USE` (ซ่อนแทน)
- ตราประทับ: ประทับมุมขวาล่าง กว้าง 24% ห่างขอบ 3% ด้วย multiply (พื้นขาวของตราสแกนไม่บังหน้า) — บนจอ/พิมพ์ด้วย CSS `.lt-stamp` · ไฟล์ Word ด้วย `sharp` ใน `normalizePhoto(bytes, stamp)` · สองที่ต้องตรงกัน (`STAMP_WIDTH`/`STAMP_MARGIN`)
- ไฟล์ Word: อ่าน+แปลงรูปทีละ 4 หน้าพร้อมกัน · `maxDuration = 60`
- ยังไม่รัน migration: ฟอร์มหนังสือทำงานเหมือนเดิม (`loadLetterPhotos` อ่านแบบไม่มี `stamped` ได้ · ตราประทับ = ไม่มี) · หน้าคลังบอกให้รัน migration
