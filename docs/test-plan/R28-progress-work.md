# R28 · ปริมาณงานที่แล้วเสร็จ แยกค่าวัสดุ/ค่าแรง + แนบหนังสือส่งมอบงาน (8 พ.ย. 2569)

คำขอเจ้าของ: "อยากแยกค่าแรงกับค่าของ เหมือน BOQ ตามสัญญา แล้วผมกรอกเปอร์เซ็นต์ไป" · "แก้ตามที่แนะนำ (ถ่วงตามมูลค่า) แล้วนำขึ้นเว็บ
ผมจะใช้แนบกับหนังสือส่งมอบงาน แต่มีปุ่มให้ติ๊กด้วย เพราะบางงานไม่ได้ใช้ปริมาณงานที่แล้วเสร็จแนบ"

## คำตอบเจ้าของ

- ติ๊กแล้ว **ดึงจากแผนงานที่บันทึกไว้** (เมนูแผนงาน) ณ สิ้นสัปดาห์ที่เลือก → พิมพ์ตารางต่อท้ายหนังสือ + เติมบรรทัด "สิ่งที่ส่งมาด้วย"
- % ของหมวด/งาน/ทั้งโครงการ **ถ่วงตามมูลค่า** (ไฟล์ Excel เดิมของห้างใช้ค่าเฉลี่ยธรรมดาของ % รายการ = นับผลงานต่ำกว่าจริง)
- 🔴 **ไม่แยกช่องกรอก %** (เจ้าของแก้คำสั่งหลังเห็นรอบแรก 8 พ.ย. 2569): "ให้โชว์ยอดเงินค่าแรงกับวัสดุ … เปอร์เซ็นกรอกที่เดียว แล้วปรับค่าแรง+วัสดุขึ้นเท่ากันตามที่กรอก"

## การออกแบบ

- ตัวอ่าน BOQ (`core.ts`): แถวรายละเอียด ปร.4 เก็บ `mat`/`lab` = ช่อง "รวม" ของค่าวัสดุ (3 ช่องก่อนยอดรวม) / ค่าแรง (1 ช่องก่อน)
  เฉพาะเมื่อบวกกันเท่ายอดของแถว · ไม่ลงตัว = ไม่แยก (แผนเก่าเหมือนเดิมทุกไบต์)
- ผลงาน: `progress.items` เหมือนเดิม — % เดียวต่อรายการ ใช้กับทั้งค่าวัสดุและค่าแรง · หน้ากรอกผลงานโชว์ "(วัสดุ … · แรง …)" ใต้รายการ/งาน
  · S-Curve/ว.124/Excel ไม่เปลี่ยน (ยอดรวมของรายการ × % เดิม)
- แผนที่บันทึกก่อน R28: ปุ่ม **เติมค่าวัสดุ/ค่าแรงจาก BOQ** ในหน้าแผนงาน (`fillSplit` จับคู่ชื่อ+ยอด · ไม่แตะยอด/ลำดับ/ผลงาน)
- หนังสือแบบ "ส่งมอบงานงวด": การ์ด **แนบปริมาณงานที่แล้วเสร็จ** (ช่องติ๊ก) → เลือกแผน + สัปดาห์ → ภาพนิ่ง `ProgressWork`
  เก็บใน `letters.fields.progressWork` (jsonb เดิม · **ไม่มี migration**) · แก้ผลงานในแผนทีหลัง หนังสือไม่เปลี่ยนจนกด "ดึงผลงานใหม่"
- กระดาษ: แผ่นแนวนอน 13 คอลัมน์ (% แล้วเสร็จคอลัมน์เดียว ก่อน "รวมมูลค่าที่แล้วเสร็จ") (ผัง R26 `.ma-fit/.ma-sheet` + `.pw-*`) หมุนลงกระดาษแนวตั้งตอนพิมพ์ · แบ่งแผ่นด้วย `pwPages()`
  (หัวหมวด/หัวงานไม่ค้างท้ายแผ่น) · ไฟล์ Word ของหนังสือไม่มีตารางนี้ (ใช้พิมพ์ / PDF)
- API: `GET /api/letters/boq?planId=…&progress=1` = แผนทั้งฉบับพร้อมผลงาน (เจ้าของเท่านั้น)
