# R19 · หนังสือบริษัท (หนังสือราชการถึงหน่วยงาน) + ทะเบียนหนังสือส่ง — แผนและตารางตรวจรับ

> คำขอเจ้าของ 20 ต.ค. 2569:
> *"ผมต้องการให้คุณทำหนังสือบริษัท ตามตัวอย่างที่ผมส่งให้ ออกแบบให้ใช้งานง่ายและรวดเร็ว"*
> แล้วตามด้วย *"สามารถนำขึ้นเว็บเป็นอีก 1 เมนูใน https://ruaynae.vercel.app/ ได้ไหม"*
>
> ต้นแบบ = หนังสือจริง 42 ฉบับ `reg001`–`reg047/2569` (Word) ที่ห้างส่งถึง
> ประธานคณะกรรมการตรวจการจ้าง โครงการปรับปรุงอาคารสำนักทะเบียนฯ มช.
> · ทุกฉบับผังเดียวกัน: หัวกระดาษ (โลโก้ + ชื่อห้าง + ที่อยู่) · เลขที่ · วันที่ ·
> เรื่อง/เรียน/อ้างถึง/สิ่งที่ส่งมาด้วย · ย่อหน้าแนะนำโครงการ · เนื้อความ · ข้อความปิด ·
> ขอแสดงความนับถือ · ชื่อผู้ลงนาม · ตำแหน่ง · กล่อง "รับเอกสารแล้ว ลงชื่อ… วันที่…"
> · ต่างกันแค่เรื่อง สิ่งที่ส่งมาด้วย และเนื้อความหนึ่งสองย่อหน้า → ทำเป็น **แบบหนังสือ** ให้กดเลือก

**สถานะ:** `☐` ยังไม่ตรวจ · `✅` ผ่านโดยมีหลักฐาน · `❌` ตก · `👤` ต้องคนตรวจ · `⚠️` ติดเงื่อนไข

> 🔴 **ห้ามปิดเฟสโดยเหลือ `☐`** (CLAUDE.md §17 ข้อ 10)

## 2 · ลำดับงาน

```
/letters ─ ออกหนังสือใหม่ ─► /letters/new
   1. เลือกแบบหนังสือ (19 แบบ · ค้นหาได้)           ← เลข "ครั้งที่/งวดที่" นับต่อจากทะเบียนให้
   2. ข้อมูลเฉพาะเรื่อง (ช่องด่วน)                   ← ข้อความ เรื่อง/สิ่งที่ส่งมาด้วย/เนื้อความ เติมให้เอง
   3. ตรวจ/แก้ รายละเอียด + ดูกระดาษ A4 สด
   ► ดาวน์โหลด Word  = บันทึกลงทะเบียน → POST /api/letters/[id]/docx → ไฟล์ reg048_<เรื่อง>.docx
   ► พิมพ์ / PDF     = บันทึกลงทะเบียน → window.print() (พิมพ์เฉพาะ .paper)
/letters/[id] = ฟอร์มเดียวกัน (แก้ · ดาวน์โหลดซ้ำ · พิมพ์ · ทำซ้ำเป็นฉบับใหม่ · ลบ)
```
