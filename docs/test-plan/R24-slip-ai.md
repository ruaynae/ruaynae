# R24 · อ่านสลิปด้วย AI ในบอท LINE (31 ต.ค. 2569)

คำขอเจ้าของ: "ส่งสลิปค่าใช้จ่ายเข้าไลน์ แล้วให้ระบบอ่านสลิปแล้วบันทึกเอง" · เลือกลอง **Gemini แบบฟรี** ก่อน

## การออกแบบ

- คีย์ Gemini API เก็บใน Vault (`slip_ai_gemini_key`) ผ่าน `set_slip_ai_key()` · หน้าจอเห็นแค่ 4 ตัวท้าย · มีคีย์ = เปิด · ล้าง = ปิด
- ส่งรูปเข้าแชท → เก็บรูปเหมือนเดิม → ถ้ายังไม่มียอดที่อ่านได้ ส่งรูป (WebP ที่บีบแล้ว) ให้ `gemini-3.5-flash-lite` (404 → `gemini-flash-lite-latest`)
- AI อ่านได้ = **ข้อเสนอ** ไม่ใช่ยอดจริง · บอทถาม "ใช่ ฿…" หรือพิมพ์ยอดที่ถูกแทน · วันที่บนสลิปไปเป็นวันที่ของการ์ดยืนยัน · ผู้รับ + เลขอ้างอิงเป็นหมายเหตุ
- ยังต้องเลือกหมวด/โครงการ และกดบันทึกบนการ์ดยืนยันเหมือนเดิม — **ไม่บันทึกเองโดยไม่มีคนกด** (อ่านเลขผิดหนึ่งหลัก = ต้นทุนผิดเงียบ ๆ)
- เลขอ้างอิงที่เคยบันทึก (ค้นในหมายเหตุ) = เตือน ไม่ห้าม
- ปิดอยู่ / โควตาหมด (429) / คีย์ผิด / อ่านไม่ได้ = ถามยอดแบบเดิม พร้อมบอกเหตุผล · การอ่านสลิปห้ามทำให้การรับรูปล้ม
- `parse.ts` ไม่เชื่อ AI: ยอด > 0 และ ≤ 99,999,999 · วันที่ พ.ศ. → ค.ศ. · อนาคต/เก่ากว่า 400 วัน/ไม่มีจริง = ทิ้ง · เลขอ้างอิงเฉพาะ `[A-Za-z0-9_-]`
