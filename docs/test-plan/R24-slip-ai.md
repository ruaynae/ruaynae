# R24 · อ่านสลิปด้วย AI ในบอท LINE (31 ต.ค. 2569)

คำขอเจ้าของ: "ส่งสลิปค่าใช้จ่ายเข้าไลน์ แล้วให้ระบบอ่านสลิปแล้วบันทึกเอง" · เลือกลอง **Gemini แบบฟรี** ก่อน

## การออกแบบ

- คีย์ Gemini API เก็บใน Vault (`slip_ai_gemini_key`) ผ่าน `set_slip_ai_key()` · หน้าจอเห็นแค่ 4 ตัวท้าย · มีคีย์ = เปิด · ล้าง = ปิด
- ข้อความที่เจ้าของพิมพ์ในสลิป (ช่อง "บันทึก") = ต้นหมายเหตุ · ถ้าเอ่ยชื่อย่อโครงการ (ไม่นับช่องว่าง/จุด) ตรงหนึ่งโครงการ → โครงการนั้นอยู่ปุ่มแรกตอนถาม (ไม่เลือกแทน)
- ส่งรูปเข้าแชท → เก็บรูปเหมือนเดิม → ถ้ายังไม่มียอดที่อ่านได้ ส่งรูป (WebP ที่บีบแล้ว) ให้ `gemini-3.5-flash-lite` (404 → `gemini-flash-lite-latest`)
- AI อ่านได้ = **ข้อเสนอ** ไม่ใช่ยอดจริง · บอทถาม "ใช่ ฿…" หรือพิมพ์ยอดที่ถูกแทน · วันที่บนสลิปไปเป็นวันที่ของการ์ดยืนยัน · ผู้รับ + เลขอ้างอิงเป็นหมายเหตุ
- ยังต้องเลือกหมวด/โครงการ และกดบันทึกบนการ์ดยืนยันเหมือนเดิม — **ไม่บันทึกเองโดยไม่มีคนกด** (อ่านเลขผิดหนึ่งหลัก = ต้นทุนผิดเงียบ ๆ)
- เลขอ้างอิงที่เคยบันทึก (ค้นในหมายเหตุ) = เตือน ไม่ห้าม
- ปิดอยู่ / โควตาหมด (429) / คีย์ผิด / อ่านไม่ได้ = ถามยอดแบบเดิม พร้อมบอกเหตุผล · การอ่านสลิปห้ามทำให้การรับรูปล้ม
- `parse.ts` ไม่เชื่อ AI: ยอด > 0 และ ≤ 99,999,999 · วันที่ พ.ศ. → ค.ศ. · อนาคต/เก่ากว่า 400 วัน/ไม่มีจริง = ทิ้ง · เลขอ้างอิงเฉพาะ `[A-Za-z0-9_-]`

## R24b · ส่งสลิปหลายใบพร้อมกัน (31 ต.ค. 2569 · เจ้าของเลือกแบบ ก "ส่งรวดเดียว แล้วยืนยันทีละใบ")

- ตาราง `line_slip_queue` (service role เท่านั้น) + RPC `bot_slip_take` / `bot_slip_next` / `bot_slip_clear` · migration `20261031120000_line_slip_queue.sql`
- AI อ่านได้ → ไม่มีใบที่กำลังทำ = ใบปัจจุบัน · มีแล้ว = เข้าคิว (สูงสุด 10) · เลขอ้างอิงเดียวกับใบปัจจุบัน = แนบรูปเพิ่ม
- บันทึก/ข้ามใบปัจจุบัน → ใบถัดไปขึ้นมาเอง ("ในคิวอีก N ใบ") · พิมพ์ "ยกเลิก" = ทิ้งทั้งคิว · ของค้างเกิน 24 ชม. ทิ้ง
- AI อ่านไม่ได้ = แนบเข้าใบปัจจุบันแบบเดิม · ยังไม่ได้รัน migration = ทำงานแบบใบเดียวเหมือนเดิม

## R24c · การ์ดยืนยันมีรูปสลิปในตัว (31 ต.ค. 2569 · เจ้าของต้องเลื่อนขึ้นลงหาสลิปทุกใบ)

- การ์ด Flex: รูปสลิป (hero · แตะดูเต็มจอ) + ยอดตัวใหญ่ + รายละเอียด + ปุ่มในการ์ด (ไม่หายเมื่อมีข้อความใหม่)
- รูปผ่าน `/api/line/slip-preview` (WebP → JPEG · ลิงก์ลงลายเซ็น HMAC ด้วย CRON_SECRET + คำนำหน้าแยกโดเมน · อายุ 7 วัน · รับเฉพาะ `slips/*.webp`)
- ปุ่มผูกรหัสสลิป — กดปุ่มบนการ์ดเก่า = "ปุ่มนั้นเป็นของสลิปใบอื่น" + การ์ดใบปัจจุบัน ไม่ยืนยัน/ข้ามผิดใบ
- ส่งหลายใบ: ตอบเฉพาะใบแรกที่เข้าคิว (ใบอื่นเงียบ) · ไม่รู้ที่อยู่เว็บ/ไม่มีกุญแจ = ข้อความล้วนแบบเดิม

|---|---|---|
| R24-C-01 | ส่งสลิป 1 ใบ → การ์ดมีรูปสลิป ยอดตัวใหญ่ ปุ่ม "ใช่ ฿…" · แตะรูป = เปิดรูปเต็ม | 👤 |
| R24-C-02 | ส่ง 5 ใบ → การ์ดใบแรก + ข้อความ "รับสลิปหลายใบแล้ว" แค่ข้อความเดียว | 👤 |
| R24-C-03 | กด "ใช่" บนการ์ดของใบที่บันทึกไปแล้ว → "ปุ่มนั้นเป็นของสลิปใบอื่น" + การ์ดใบปัจจุบัน ไม่บันทึกผิดใบ | 👤 |
