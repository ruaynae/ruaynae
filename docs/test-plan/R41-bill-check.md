# R41 · ระบบตรวจบิล (11–12 พ.ย. 2569)

คำขอเจ้าของ: "จ่ายเงินไปแล้ว ได้บิลกลับมาหรือยัง" — อัปโหลดบิล (PDF สแกนทีละปึก / รูป / ส่งทาง LINE) → AI อ่าน → จับคู่กับรายจ่ายที่คีย์ไว้ → รายการรายจ่ายที่ยังไม่ได้บิล
คำตอบเจ้าของ: PDF สแกนทีละเยอะ + ถ่ายรูปส่ง LINE ทีละรูป · โอนครั้งเดียวจ่ายหลายบิล "ไม่บ่อยแต่มี" · ไม่ต้องมีบิล = ค่าแรง/เบี้ยเลี้ยง · เริ่มตรวจจากเดือนนี้ · บิลส่งสำนักงานบัญชียื่นสรรพากร

migration `20261112090000_bills.sql` (เจ้าของรันเอง) · ตาราง `bills` + `bill_matches` (หลายต่อหลาย) · `categories.bill_required` · `transactions.bill_not_required` · `app_settings.bill_check_from` (1 พ.ย. 2569)
