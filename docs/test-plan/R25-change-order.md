# R25 · ตารางงานเพิ่ม-ลด เชื่อมกับใบปะหน้าหนังสือ (1 พ.ย. 2569)

คำขอเจ้าของ: "ออกแบบตารางงานเพิ่ม-ลด แล้วนำตัวเลขไปเชื่อมกับใบปะหน้าของหนังสืองานเพิ่มลด" · แนบตารางเดิม 2 แบบ

## คำตอบเจ้าของ

- รูปแบบ = **แบบแนะนำ**: หัวกระดาษแบบที่ 1 (กลุ่มงาน · ชื่อโครงการ · สถานที่ · หน่วยงานเจ้าของ · แบบเลขที่)
  + โครงตารางแบบที่ 2 (บล็อกงานลด → รวม · Factor F · รวมทั้งหมด / บล็อกงานเพิ่มแบบเดียวกัน → ส่วนต่าง) + คอลัมน์หมายเหตุ
- ไฟล์ = **Excel + พิมพ์จากเว็บ**
- รายการงานลด **เลือกจาก BOQ ที่บันทึกไว้ในเมนูแผนงานได้**

## การออกแบบ

- อยู่ในหน้าหนังสือแบบ "ขออนุมัติงานเพิ่ม / งานลด" — การ์ด "ตารางงานเพิ่ม-ลด" ใต้ข้อมูลเฉพาะเรื่อง → กล่องแก้ตารางเต็มจอ
- เก็บใน `letters.fields.changeOrder` (jsonb เดิม) — **ไม่ต้องรัน migration** · ตัวตรวจ `parseChangeOrder()` ทั้งตอนรับจากฟอร์มและตอนอ่านกลับ
- สูตรเงินที่เดียว `src/lib/change-order.ts` (ไฟล์ล้วน · unit test):
  รวมแถว = ROUND(จำนวน × ราคา/หน่วย, 2) แยกวัสดุ/แรง · Factor F ของบล็อก = ROUND(รวม × (F − 1), 2) · ส่วนต่าง = เพิ่ม − ลด
  - ⚠️ Factor F คิดแยกบล็อกตามแบบที่ 2 — ถ้าเทียบกับแบบที่ 1 (คูณส่วนต่างครั้งเดียว) อาจต่างกัน 1 สตางค์
  - ⚠️ ราคา/หน่วยที่มีทศนิยมเกิน 2 ตำแหน่งในไฟล์เดิม (เช่น 78,505.3367) กรอกได้ถึง 4 ตำแหน่ง · ยอดแถวปัดทีละแถว ผลรวมจึงเท่าผลบวกของแถวที่เห็นเสมอ
- ใบปะหน้า: มีรายการในตาราง → ช่อง "ประเภท" (งานเพิ่ม ถ้าส่วนต่าง ≥ 0 · งานลด ถ้าติดลบ) และ "จำนวนเงิน" (ค่าสัมบูรณ์) ถูกล็อกให้ตามตาราง แล้วเรื่อง/เนื้อความ/คำอ่านบาทเติมใหม่ (เฉพาะข้อความที่ยังไม่ถูกแก้เอง)
  - เนื้อความถูกแก้เองแล้วยอดไม่ตรงตาราง → แถบเตือน + ปุ่ม "ใช้ข้อความตามตาราง"
  - สิ่งที่ส่งมาด้วยของแบบนี้ = "แบบแสดงรายการ ปริมาณงาน และราคา งานเพิ่ม-ลด 1 ชุด"
- พิมพ์ / PDF: ตารางเป็นแผ่น A4 ต่อจากหนังสือ (ต้นฉบับเท่านั้น · ก่อนรูปแนบ) · หัวตารางพิมพ์ซ้ำทุกหน้า
- Excel: สร้างในเบราว์เซอร์ (`change-order-xlsx.ts`) · ทุกช่องเงินเป็นสูตรที่ให้ผลเท่า `change-order.ts` + ค่าที่คำนวณไว้แล้ว
- เลือกจาก BOQ: `GET /api/letters/boq` (เจ้าของ) · แผนของโครงการเดียวกับชุดเลขขึ้นก่อน · งานที่เลือกได้แถวหัวข้อ + รายการ · ราคาต่อหน่วย = ค่างานต้นทุน ÷ จำนวน ใส่ช่องค่าวัสดุ (BOQ ที่บันทึกไว้ไม่แยกค่าแรง) · ตารางเปล่า → Factor F ของแผนมาด้วย
- ไฟล์ Word ของหนังสือ**ไม่มี**ตาราง (แนบ Excel แยก หรือใช้ปุ่มพิมพ์)
