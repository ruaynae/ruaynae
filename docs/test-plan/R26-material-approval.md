# R26 · หนังสือขออนุมัติใช้วัสดุ 2 รูปแบบ + ตารางรายการขออนุมัติใช้วัสดุ (3 พ.ย. 2569)

คำขอเจ้าของ: "หนังสือขออนุมัติใช้วัสดุที่ผมใช้อยู่มี 2 รูปแบบ" · แนบ `agro009/2569` (ครั้งที่ 4) และ `reg033/2569` (ครั้งที่ 7) · เลือก "เพิ่มฟีเจอร์ในเว็บแอป RUAY NAE"

## สองรูปแบบ (ถอดจากไฟล์จริง)

| | แบบที่ 1 · ระบุในเนื้อหา (`agro009`) | แบบที่ 2 · แนบตาราง (`reg033`) |
|---|---|---|
| เนื้อหา | ย่อหน้าแนะนำ + "มีความประสงค์ขออนุมัติใช้วัสดุดังต่อไปนี้ …" + ข้อ 1. 2. … (รายการ + ยี่ห้อ/รุ่น) | ย่อหน้าแนะนำ + "มีความประสงค์ขออนุมัติใช้วัสดุตามเอกสารดังแนบ …" |
| สิ่งที่ส่งมาด้วย | รายละเอียดวัสดุ 1 ชุด | 1. รายการขออนุมัติวัสดุ 1 ชุด · 2. รายละเอียดวัสดุ 1 ชุด |
| แผ่นแนบ | แค็ตตาล็อก (รูปแนบท้าย R19) | **ตารางรายการขออนุมัติใช้วัสดุ** A4 แนวนอน + แค็ตตาล็อก |

ตาราง 7 คอลัมน์: เลขที่ · รายการวัสดุ · รูปแบบรายการ · แบบแสดงปริมาณราคา · รายการประกอบแบบ · รายละเอียดขออนุมัติใช้ · หมายเหตุ
· หัวตาราง: โครงการ · ผู้รับจ้าง (หัวกระดาษ) · สัญญาจ้าง · เรื่อง (ของหนังสือ) · ช่องว่างพิมพ์ "- ไม่ระบุ" ตามแบบเดิม

## การออกแบบ

- แบบหนังสือ "ขออนุมัติใช้วัสดุ" มีช่องด่วนใหม่ **"รูปแบบหนังสือ"** (`fields.style` · แนบตาราง / ระบุในเนื้อหา) · หนังสือเก่าที่ไม่มีช่องนี้ = แนบตาราง (ข้อความเดิมทุกตัวอักษร)
- การ์ด "รายการวัสดุที่ขออนุมัติ" กรอก**ชุดเดียว**ใช้ได้ทั้งสองแบบ — สลับรูปแบบไม่เสียรายการ
  · ระบุในเนื้อหา: แสดงแค่ รายการ + ยี่ห้อ/รุ่น → ข้อในเนื้อหา = `maLine()` · เนื้อหาเติมใหม่เฉพาะตอนยังไม่ถูกแก้เอง (กลไก `gen` เดิม)
  · แนบตาราง: ครบ 7 คอลัมน์ + หัวตาราง · สัญญาจ้างเว้นว่าง = ดึงจากบรรทัด "อ้างถึง" ที่เป็นสัญญา
- เก็บใน `letters.fields.materialApproval` (jsonb เดิม) — **ไม่ต้องรัน migration** · ตัวตรวจ `parseMaterialApproval()` ทั้งขาเข้าและขาออก · แถวว่างไม่ถูกเก็บ · เก็บเฉพาะแบบ `material`
- สูตร/ตัวตรวจที่เดียว `src/lib/material-approval.ts` (ไฟล์ล้วน · unit test)
- พิมพ์ / PDF: แผ่นแนวนอนต่อจากหนังสือ (ต้นฉบับเท่านั้น · ก่อนรูปแนบ) ด้วย named page `@page ma-land` · บนจอย่อ 0.7071 ให้กว้างเท่าหนังสือ
- Excel: `material-approval-xlsx.ts` (A4 แนวนอน · หัวตารางพิมพ์ซ้ำ) · ไฟล์ Word ของหนังสือ**ไม่มี**ตาราง (แบบที่ 1 มีครบเพราะอยู่ในเนื้อหา)
