# R33–R35 · ตารางแนบหนังสือบริษัท (8 พ.ย. 2569)

แบบหนังสือใหม่ใน `/letters` ที่มีตารางแนบท้าย (พิมพ์/PDF · ไฟล์ Word ไม่มีตาราง) · เก็บใน `letters.fields` (jsonb เดิม · ไม่มี migration)
